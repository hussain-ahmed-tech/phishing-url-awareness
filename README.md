# Phishing Link Detector 🛡️
**Author:** Hussain Ahmed  
**Batch:** AI-Powered Cybersecurity (EWB Internship)

## Overview
This Python-based mini-project is designed to analyze URLs and identify common indicators of phishing attacks, such as the use of raw IP addresses, lack of HTTPS encryption, and obfuscation using the `@` symbol. 

## Features
* **Static URL analysis**: Safely parses text without connecting to the web.
* **IP Detection**: Identifies if the domain is a direct IP address.
* **Protocol Check**: Flags unencrypted HTTP connections.
* **Syntax Scanning**: Highlights suspicious characters like `@`.

## How to Run
1. Open your terminal (Command Prompt or PowerShell).
2. Navigate to this project directory.
3. Run the script using the command: `python phishing_checker.py`
